MAESA ZUDA PRATAMA — PORTOFOLIO WEB

CARA MENJALANKAN
1. Ekstrak file ZIP ke folder yang kamu inginkan.
2. Buka folder Maesa-Portfolio-Updated di Visual Studio Code.
3. Pastikan index.html, style.css, script.js dan folder assets berada dalam satu project.
4. Jalankan index.html menggunakan ekstensi Live Server (klik kanan index.html > Open with Live Server).
   Bisa juga membuka index.html langsung di browser, tetapi Live Server lebih nyaman untuk pengembangan.

STRUKTUR
- index.html : konten dan struktur halaman
- style.css  : tema, layout, responsivitas, dan animasi
- script.js  : dark/light mode, navigasi mobile, filter skill, scroll reveal, dan form email
- assets/KBR.jpeg : foto profil
- assets/CV-Maesa-Zuda-Pratama.pdf : CV yang sudah kamu sertakan

CATATAN SEBELUM DIPUBLIKASIKAN
- Cek kembali tanggal pengalaman kerja, nama posisi, dan detail pendidikan.
- SocialRelation diberi label proyek akademik yang sedang dikembangkan; dua kartu lainnya secara eksplisit dilabeli konsep/studi kasus.
- Form kontak membuka aplikasi email default; form belum mengirim ke server.
- Pastikan kamu memang ingin menampilkan email, tautan media sosial, dan nomor WhatsApp pada website publik.
- Skill menggambarkan area pembelajaran, bukan tingkat kemahiran profesional. Sesuaikan dengan pengalaman aktual.
